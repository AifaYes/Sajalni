# 🇹🇳 Sajalni Cert AI - Automation & Intelligence Pipeline

An end-to-end automated platform that processes user support emails regarding the **Sajalni** device registration platform in Tunisia. 

The system leverages **FastAPI**, **Qdrant Vector DB**, **Sentence Transformers**, and **n8n workflow automation** to classify user queries, retrieve relevant response templates, require human validation/interactive link clicking, and automatically send finalized support replies.

---

## 🏗️ System Architecture & Workflow

[ User Email ] ➔ [ n8n Trigger ] ➔ [ FastAPI AI Classifier ] ➔ [ Qdrant Knowledge Base ]
│
[ Final Email Sent ] ◄─ [ Wait Click Webhook ] ◄─ [ Interactive Link ] ┘

## 🔄 Detailed n8n Workflow Breakdown

The n8n workflow follows a 5-stage pipeline:

```text
[ Email Read ] ➔ [ HTTP Request ] ➔ [ Respond to Webhook ] ➔ [ Wait for Webhook ] ➔ [ Send Email ]
  (Réception)       (Appel IA)       (Création du lien)     (Attente clic)      (Envoi final)
📦 Node-by-Node Configuration & Credentials
1️⃣ Node 1: Email Read (IMAP Email Trigger / Email Read)
Purpose: Monitors the inbox for incoming emails requesting support regarding Sajalni.

Credentials Required:

Credential Type: IMAP / Gmail OAuth2 / App Password

Host: imap.gmail.com (for Gmail) or your custom mail server host.

Port: 993 (SSL/TLS enabled).

User / Email: your-support-email@domain.com

Password: Your Email Password or Gmail App Password (never your plain Google password).

Node Parameters:

Action: Fetch Emails / On New Email

Mailbox: INBOX

Format: Resolved (Extracts From, Subject, Text Body, HTML Body).

2️⃣ Node 2: HTTP Request (Appel IA - FastAPI Server)
Purpose: Sends the raw email text content to the local FastAPI AI backend for classification and response generation.

Credentials Required: None (Internal Docker Network communication) or API Key if configured.

Node Parameters:

Method: POST

URL: http://fastapi-app:8000/classify (or http://localhost:8000/classify if testing outside Docker)

Send Body: JSON

Body Parameters:

JSON
{
  "text": "={{ $json.text }}"
}
Expected Output from FastAPI:

category (e.g., IMEI_REGISTRATION, TAX_INQUIRY)

suggested_reply (The pre-drafted template populated with vector search results)

3️⃣ Node 3: Respond to Webhook (Création du lien & Validation)
Purpose: Generates a unique validation payload/link that allows a supervisor or system event to approve sending the response.

Credentials Required: None.

Node Parameters:

Response Mode: On Received

Response Body: Constructs an HTML email or interactive validation payload containing a target callback link pointing to the Wait Node Webhook URL.

4️⃣ Node 4: Wait for Webhook (Attente clic / Human-in-the-Loop)
Purpose: Pauses the n8n execution branch until a human operator clicks "Approve / Send" or an external validation event fires the webhook.

Credentials Required: None.

Node Parameters:

Resume Mode: On Webhook Call

Webhook Path: Automatically generated by n8n (e.g., http://localhost:5678/webhook-waiting/...)

HTTP Method: GET or POST

5️⃣ Node 5: Send Email (Envoi final)
Purpose: Sends the finalized, AI-generated/approved reply back to the original sender.

Credentials Required:

Credential Type: SMTP / Gmail OAuth2

Host: smtp.gmail.com

Port: 465 (SSL) or 587 (STARTTLS)

User: your-support-email@domain.com

Password: Gmail App Password.

Node Parameters:

To Email: ={{ $node["Email Read"].json["from"]["text"] }}

Subject: Re: ={{ $node["Email Read"].json["subject"] }}

Text / HTML Body: ={{ $node["HTTP Request"].json["suggested_reply"] }}

🚀 Quickstart with Docker Compose
1. Prerequisites
Docker Engine & Docker Compose installed.

A .env file containing secrets (never committed to GitHub).

2. Launching the Stack
Run the following command in your terminal to build images and launch all services in detached mode:

Bash
docker compose up -d --build
3. What Happens automatically:
qdrant starts the vector database on ports 6333 / 6334.

sajalni-init-db container runs the seed.py script to populate Qdrant vector collections and exits cleanly.

fastapi-app launches the classification API on port 8000.

n8n starts the workflow engine on port 5678.
